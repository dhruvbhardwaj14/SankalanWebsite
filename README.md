# Sankalan Website

**Sankalan Website** is the official event platform for the Department of Computer Science's annual tech event **Sankalan**. It serves as a one-stop destination for event registrations, schedules, updates, team introductions, and more — all in a sleek, responsive, and theme-oriented design.

🌐 [Live Demo](https://sankalan.ducss.tech/)

---

## 🚀 Features

- 🔗 **Registration Button** with Unstop integration and live countdown
- 📖 **About Sankalan** section with mission, vision, timeline, and past event gallery
- 🧩 **Events Page** categorized into Technical and Non-Technical tabs, each with detailed rules and registration links
- 👥 **Team Page** showcasing the organizing team with photos, names, and social links
- 🤝 **Sponsors Page** for current and past sponsors
- ❓ **FAQ Page** for common questions
- 🗓️ **Updates Page** for live schedule, event timeline, and push notifications
- 🏆 **Results Page** listing winners and event outcomes
- 📞 **Contact Us** and **Privacy Policy** pages
- 🎨 Fully **responsive** and **theme-based** UI

---

## 🛠 Tech Stack

- **Frontend**: React, CSS, Bootstrap
- **Hosting**: Vercel
- **Backend**: None (static + API-free)

---

## ⚙️ Getting Started

Clone the repository and run the project locally:

```bash
git clone https://github.com/yourusername/sankalan-website.git
cd sankalan-website
npm install
npm start
```

No additional setup or `.env` configuration needed.

---

## 📁 Folder Structure

```
src/
├── Components/        # Reusable UI components (Navbar, Footer, etc.)
├── Data/              # Static data files (FAQs, team info)
├── Images/            # Gallery and asset images
├── Pages/             # Main pages (Home, Events, Results, etc.)
├── utils/             # Utility functions
├── App.css            # Global styles
├── App.js             # Main app wrapper with routing
├── index.css          # Base styles
├── index.js           # React DOM entry point
```
